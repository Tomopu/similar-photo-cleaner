# 機能設計

## アプリ概要
本アプリは、iPhone内に保存された画像をすべて読み込み、アルバム内に存在する画像の整理を補助することを目的としている。
なお、本アプリでは、画像の類似性、重複性、解像度を検出するにあたり、Apple Intelligence のAPIを使用する。()

## 機能
- 類似した画像、重複した画像、低解像度の画像を検出し、ユーザーに削除や整理の提案を行う。
- ユーザーが指定した条件に基づいて画像をフィルタリングし、スワイプカード形式で「キープ」と「削除」を選択できるインターフェースを提供する。
- ユーザーが誤って削除した画像を復元できる機能を提供する。

### パスワード関係
### 優先度: 高
- ユーザーがパスワードを設定できる機能
- ユーザーがパスワードをリセットできる機能
### 優先度: 中
- パスワードの強度を評価する機能
- 生体認証を利用したアプリロック機能
### 優先度: 低
- なし
